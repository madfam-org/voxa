## Why Mulberry

Voxa is a commercial product. ARASAAC pictograms are licensed **CC BY-NC-SA**
(non-commercial only), so Voxa no longer serves, searches or exports them.
Mulberry Symbols are licensed **CC BY-SA 4.0**, which permits commercial use
with attribution and share-alike. Mulberry is Voxa's symbol library.

## Full set (`EN/`)

`EN/` holds the complete upstream Mulberry `EN/` directory, vendored
**unmodified** with upstream filenames, plus upstream `LICENSE.txt`:

- Upstream: https://github.com/mulberrysymbols/mulberry-symbols
- Version: 3.6.1, commit `9cbab9f400c5de44e2bc58839cca07294aadb086` (2026-08-21)
- Files: 3,436 SVG, 33,772,809 bytes

The full set lives in its own `EN/` directory (not beside the slug-named core
files below) so that upstream names such as `I.svg` never collide with Voxa's
`i.svg` on case-insensitive filesystems, and so every path matches upstream 1:1.

The search index that maps keywords (English, French from upstream metadata,
and a hand-curated Spanish list) to these files is
`packages/symbols/src/mulberry-index.json`, rebuilt by
`packages/symbols/scripts/build-mulberry-index.mjs`.

Credits page shown to users: `/legal/symbols` (es/en/fr).
